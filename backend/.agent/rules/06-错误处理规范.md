# 错误处理规范

## 1. 分层

Repository：

负责数据库错误。

Service：

负责业务错误。

Handler：

负责 HTTP 错误映射。

例如：

数据库：

duplicate key

Service：

ErrUserAlreadyExists

Handler：

409 Conflict

---

## 2. 内部错误

不要直接返回：

pq: duplicate key value violates unique constraint

应该转换为：

{
"code": "USER_ALREADY_EXISTS",
"message": "User already exists",
"request_id": "..."
}

---

## 3. Agent 错误

Agent Timeout：

504 Gateway Timeout

Agent Connection Refused：

502 Bad Gateway

Agent 返回异常：

502 Bad Gateway

不要将 Python Stack Trace 返回客户端。

---

## 4. 错误包装

推荐：

fmt.Errorf("查询用户失败: %w", err)

不要破坏 Error Chain。

---

## 5. Request ID

错误响应尽可能包含：

request_id
