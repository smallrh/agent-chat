# 测试规范

## 1. 必须测试

至少覆盖：

- 注册成功
- 重复注册
- 登录成功
- 密码错误
- 禁用用户
- JWT 正常
- JWT 过期
- JWT 签名错误
- JWT issuer 错误
- JWT algorithm 错误
- 没有 Authorization
- Authorization 格式错误
- Refresh Token 成功
- Refresh Token Rotation
- Refresh Token Replay
- Logout
- 并发注册
- 伪造 X-User-Id
- Agent Timeout
- Agent 不可用
- Request ID
- Rate Limit

---

## 2. 最重要的安全测试

客户端：

Authorization: Bearer <User-A>

X-User-Id: <User-B>

Go 最终发送：

X-User-Id: <User-A>

绝对不能：

X-User-Id: <User-B>

---

## 3. Table Driven Test

纯逻辑测试优先使用 Table-driven Test。

---

## 4. HTTP Test

HTTP Handler、Middleware 使用：

httptest

---

## 5. Integration Test

涉及：

PostgreSQL
Redis
Agent

优先使用真实依赖进行 Integration Test。

可以使用 Docker Compose：

PostgreSQL
Redis
Mock Agent

---

## 6. 测试结果

只有实际执行：

go test ./...

并成功后，才能报告：

[PASS]

如果没有执行：

[NOT RUN]

禁止伪造测试结果。

---

## 7. 回归测试

修复 Bug 后，应尽可能增加对应 Regression Test。
