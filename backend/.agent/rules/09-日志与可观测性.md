# 日志与可观测性规范

## 1. Request ID

每个请求必须存在：

X-Request-Id

客户端没有提供时：

Go 自动生成 UUID。

---

## 2. Request ID 传递

保持：

Client
↓
Go
↓
Agent
↓
Kafka
↓
Memory Worker

使用同一个 Request ID。

---

## 3. 日志

使用结构化日志。

例如：

logger.Info(
"login success",
"request_id", requestID,
"user_uuid", userUUID,
)

---

## 4. 禁止敏感日志

禁止：

password
password_hash
access_token
refresh_token
JWT
private_key
Authorization
Cookie

---

## 5. 登录日志

允许：

login success
request_id=xxx
user_uuid=xxx

不允许：

login success
password=xxx
token=xxx

---

## 6. Health

/health：

只表示进程存活。

/ready：

检查关键依赖是否可用。

---

## 7. Graceful Shutdown

收到：

SIGTERM
SIGINT

必须：

1. 停止接收新请求。
2. 等待正在处理的请求。
3. 关闭 HTTP Server。
4. 关闭 Redis。
5. 关闭 PostgreSQL。
6. 退出。
